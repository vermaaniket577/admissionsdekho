# AdmissionsDekho - University Admission Guidance & Support Portal

High-performance Laravel web application providing 1:1 free admission counseling, statutory college verification (UGC, AICTE, BCI, PCI, INC, NCTE), cutoff analysis, and course guidance for UG, PG & PhD programs.

## Features
- **Speed Optimized**: Compiled Vite static CSS/JS bundles, Gzip compression, and browser caching.
- **Dynamic SEO Engine**: XML sitemap generator, OpenGraph metadata, and Schema.org structured JSON-LD.
- **Lead Capture & Chatbot**: Real-time AI counseling chatbot with automated WhatsApp & database lead routing.
- **Control Panel**: Admin management for leads, blogs, and site settings.
